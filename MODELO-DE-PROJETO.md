# Modelo de projeto — padrão do portfólio

Use este modelo em **todo projeto novo**. Copie o bloco abaixo para o `README.md` do repositório e preencha.

## Checklist do repositório

- [ ] Nome em minúsculas com hífen: `analise-<tema>` (ex.: `analise-estoque-armazem`)
- [ ] Descrição curta (1 linha) e **topics**: `data-analysis`, `dashboard` + ferramentas usadas
- [ ] Pasta `assets/` com `cover.jpg` (1600×900) e, se houver, `preview.gif` e vídeo curto
- [ ] Dados **fictícios ou públicos** (nunca dados pessoais ou da empresa)
- [ ] Demonstração publicada (GitHub Pages, Tableau Public ou Power BI) e link no topo do README
- [ ] Projeto adicionado ao site do portfólio e fixado no perfil (se for destaque)
- [ ] Post no LinkedIn com o vídeo/GIF e o link
