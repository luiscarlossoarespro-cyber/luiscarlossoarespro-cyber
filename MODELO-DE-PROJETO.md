# Modelo de projeto — padrão do portfólio

Use este modelo em **todo projeto novo**. É o mesmo formato dos projetos ERP Financeiro, Aurora Comercial e Netflix.

## Checklist do repositório

- [ ] Nome em minúsculas com hífen: `analise-<tema>` (ex.: `analise-estoque-armazem`)
- [ ] Descrição curta (1 linha), link do site em **Website** e **topics**: `data-analysis`, `dashboard` + ferramentas
- [ ] Pasta `assets/` com `cover.png` (print do dashboard, 1536×682 ou maior)
- [ ] **Vídeo de demonstração** (40 a 80 s, com legendas) anexado no topo do README
- [ ] Dados **fictícios ou públicos** (nunca dados pessoais ou da empresa)
- [ ] Demonstração publicada (GitHub Pages, Tableau Public ou Power BI) com botão no topo
- [ ] Projeto adicionado ao site do portfólio, ao README do perfil e fixado no perfil
- [ ] Post no LinkedIn com o vídeo e o link
